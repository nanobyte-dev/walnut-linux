# allowed-processes.txt: what a standard Walnut desktop runs while a benchmark or session runs
# (checked by proccheck.py on processes-{start,mid,end}.txt; docs/games/SUITE.md "Process check").
#
# One entry a line, matched against the process name (ps comm, 15 characters, shell-style globs):
#   name            allowed, whatever it uses
#   name ~ REGEX    allowed when the command line matches REGEX (for interpreters: python3, sh)
#   !name           never allowed (a browser, a second game, a package manager, a compiler): the run is
#                   marked unexpected= even when the process is idle
# A process that is none of these is unexpected when it uses more than 2% CPU (ps's pcpu: the share
# since the process started) or 20 MB of RSS. Always allowed without an entry: kernel threads, the
# harness itself (the shell that runs client.sh, its ancestors, everything it started: the game under
# test and its helpers).
