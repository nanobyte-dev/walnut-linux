Debian's `scummvm`, unpatched. It runs each of these games from its original data: the free ones from
Debian's packages, the others from your own copy, which Walnut Games makes into a package. Every game
has its own menu entry that starts it directly, fullscreen, with the pad as the mouse; ScummVM's own
launcher stays in the menu for everything else.
