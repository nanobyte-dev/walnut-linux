# Atomic Bomberman: technical notes

## Engine options

- elraro/atomic-bomberman (the pick: C++20, SDL3, GL 3.3, GPL-3, the only one with the original data; 17 stars, 2026-10-12)
- fpc_atomic (a playable clone with network, Free Pascal/Lazarus; 58 stars)
- Bombman (a Python clone, 2017)
- BomberClone and Mr.Boom, open clones we ship (gamedb:bomberclone, gamedb:mrboom)
