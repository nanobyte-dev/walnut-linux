Beneath a Steel Sky runs on ScummVM with the free CD version Debian packages (with speech), installed
by Walnut Games; the menu entry starts the game directly, fullscreen with the picture between bars. A
first run on the PS3 started its intro with the sound playing. Nobody has played a session of it on
Walnut yet.
