Drascula runs on ScummVM with the free release Debian packages and its CD music, installed by Walnut
Games; the menu entry starts the English version directly, fullscreen with the picture between bars. A smoke
test on the PS3 in October couldn't identify the data package of then; the current one starts on the PC.
Nobody has played a session of it on Walnut yet.
