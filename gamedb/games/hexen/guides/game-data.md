# Setting up the game data

## Which copies work

- **Hexen: Beyond Heretic 1.1**: a CD, an installed copy (Steam: `common/Hexen`) or GOG's installer (`setup_hexen_beyond_heretic_1.1_(42801).exe`, which has no Deathkings). Version 1.0 (the floppies and the first CD) does not run and is refused; Raven's update to 1.1 isn't applied for you yet.
- **The Macintosh CD's** `Hexen.WAD` is taken as a 1.1 copy (tagged `mac`): it is the same game with Macintosh fonts and menu art, but it has no GENMIDI instrument bank, so DSDA-Doom's OPL music player is unavailable with it; our default player (fluidsynth) plays the same music lumps.
- **Deathkings of the Dark Citadel**, the expansion, is optional: `HEXDD.WAD` from its CD or an installed copy (Steam: `common/Hexen Deathkings of the Dark Citadel`). It gets its own entry in Play.
