# Jazz Jackrabbit 2: technical notes

## Engine options

- Jazz² Resurrection (deathkiller/jazz2-native: the pick, the only complete option; own C++ engine, GL 3.3 / GLES 3; 716 stars, 2026-10-17)
- deathkiller/jazz2 (the older C#/.NET version: no)
- Project Carrot (abandoned C++/Qt)
- jazzjackrabbit2-decompiled (a decompiler dump, not playable)
