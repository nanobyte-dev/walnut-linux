# System Shock (Shockolate): technical notes

## Research

What the surveys and plans said about it, newest first; each line names its source, the section and the date.

- 2026-10-27, a web check (the user asked about the era's shooters): Shockolate is a cross-platform source port built on Night Dive's PowerPC source release, SDL2, GPL-3 code with commercial data; CD-ROM or Enhanced Edition assets go in res/data, floppy assets can't be loaded; early reports called it somewhat crashy and noted missing movies and audio logs. Packaged by OpenBSD (games/shockolate), no Linux distribution package found.
