# Xonotic: technical notes

## Research

What the surveys and plans said about it, newest first; each line names its source, the section and the date.

- 2026-10-26, [docs/backlog/games.md](../../../docs/backlog/games.md), "Games to smoke next, and Wesnoth's music": package it as `xonotic-gl2` after Nexuiz runs on `darkplaces-gl2`; 1.2 GB of data, RAM is the risk; not started.
- 2026-10-19, [game-reeval.md](../../research/game-reeval.md), "Ranked table": no hard no: Debian's darkplaces requests GL 3.2 core, but the engine has a `USE_GLES2` build (vid_sdl.c, makefile.inc lines 247/265) and nv30 does GLES 2.0. RAM estimate 700 MB-1.2 GB at low (not measured), textures dominate (`gl_picmip`, `r_picmipworld`). Effort L. Verdict: not worth it now (revisit after darkplaces-gl2/Nexuiz runs).
- 2026-10-19, [gl3-census-d-fps.md](../../research/gl3-census-d-fps.md), "Xonotic (DarkPlaces, release 0.8.6 of 2023-06-20 and engine git master of 2026-01-22)": 0.8.6 is NOT GL3-blocked: its own DarkPlaces still has the GL 1.1/1.3/2.0 renderpaths and runs on GL 2.1 + GLSL 1.20 as shipped (measured: "Using GL2.0 rendering path", 36 shaders all `#version 120`). Only engine master and Debian's darkplaces dropped them; master's GLES2 path is no way out (doesn't compile natively, no S3TC, no 3D lightgrid). Route: build the 0.8.6 engine for ppc64 like darkplaces-gl2 (S-M). Cost: about 200 MB of textures, 848 MB PC RSS (the-big-keybench), ~450 draws and 1945 GL calls a frame. Not in Debian. Data free, 1180 MB (data pk3 317 + maps 626 + nexcompat 125 + music 111). Scores: popularity 5, novelty 5, playability 2, effort M.
- 2026-10-19, [gl3-census.md](../../research/gl3-census.md), "The top 3 and first steps": rank 2. First steps: Nexuiz Classic on our darkplaces-gl2 first (PLAN 1.12, decision D12); package the 0.8.6 engine as `xonotic-gl2` the way darkplaces-gl2 was done (`-std=gnu17`, no SSE rasterizer off x86, the Debian link patches), checking DP_QC_FS_SEARCH_PACKFILE (the one extension its QuakeC checks that our 2018 snapshot lacks); a lean config like nexuiz-lean.cfg and a PC re-measure; small maps; a data package only after the user decides on disk.
- 2026-10-16, [game-candidates.md](../../research/game-candidates.md), "Candidates": not in Debian, about 1 GB of data; DarkPlaces GL 3.2; benchmark the-big-benchmark.sh. Verdict: out (Debian's darkplaces is GL 3.2 core only since 0~20180908, "Surprises").
