# packages/: the Debian source packages we build that don't belong to one game, one directory each, named like the package (`make <name>-deb`).
`walnut/` is our own code, `patched/` is Debian's or upstream's source with our patches, `repackaged/` is upstream releases we package unchanged, `licensed/` is the metapackage of the game data we may not redistribute (built here only, never public). A game's packages and its licensed data live in its bundle under `gamedb/games/<id>/`, an engine's under `gamedb/engines/<e>/`.
Touch it to change what goes on the PS3; how a package is built is in docs/PACKAGING.md, the layout in docs/LAYOUT.md.
