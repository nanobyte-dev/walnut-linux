# tools/ci-skips.txt: what `tools/run-tests.sh --ci` (GitHub's runner, .github/workflows/walnut-tests.yml) may skip.
# One key per line, then the reason: a suite (xmoto-glbatch), a part of one (suite:part, the key a "SKIP suite:part ..."
# line names), or suite:unittest (a unittest skip). A skip that is not listed fails the run, so a missing prerequisite
# never reads as a pass. An entry is a hole in the CI's coverage: list only what the runner cannot provide (the build/work
# trees, ppc64 sysroots and qemu, tools Ubuntu does not carry), never a failing test. An entry that did not skip is only
# mentioned in the log.
