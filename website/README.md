# website/: walnut.nanobyte.dev's content: site/ (the static front page) and gamedb/ (the Walnut Games database, a Hugo site built by tools/gamedb/build.sh).
A push touching either publishes the site (.github/workflows/walnut-site.yml, or `make walnut-site`).
Touch it to change the site or a game's catalog entry (docs/GAMEDB.md).
