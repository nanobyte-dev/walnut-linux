3. By hand

Copy the files to the paths below as root (sudo cp), with the names exactly as written, upper and lower case included: Linux tells them apart. Where a file has several accepted versions, any one of them does. Check a copy with sha256sum FILE (sha1sum or md5sum where the table says so) and compare the sum. Files copied by hand belong to no package: Walnut Games goes by the packages, so it still shows the data as missing, and Remove data leaves them alone.
